## Copy-ready messaging

Long: `A DBX plugin for everyday server operations with password, private-key, SSH Agent,

## Scope note

These assets show the plugin UI and offline capabilities. A live SSH host, DBX.app host bridge,
Docker test container, and platform installer are separate runtime environments; use the CI,
smoke-test, and release notes for verified claims.
